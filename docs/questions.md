# Банк вопросов

Источник правды — `src/questions/bank.json` (версия 8); этот файл — читаемая копия по сферам.
141 вопрос, тест только для пар: «Партнёр как друг» — 62, «Отношения» — 58, «Эмоциональная зрелость» — 21 (в конце теста, на проценты не влияет). 🔒 — можно пропустить.

## Принципы составления

1. **Одна ось.** Полюса взаимоисключающие: нельзя честно согласиться с обоими. Середина (5) — «зависит» или «всё равно».
2. **Без «правильного» ответа.** Оба полюса звучат приемлемо, без оценочных слов; «одобряемый» полюс то слева, то справа.
3. **Конкретика.** Ситуация или прошлое поведение вместо абстрактной самооценки; никаких сумм в рублях.
4. **Одна тема на вопрос.** Без двойных вопросов и подсказок в формулировке.
5. **Только значимое.** Края шкалы считаются «критично» и могут дать красный флаг, поэтому каждая тема — такая, где расхождение реально влияет на отношения.
6. **Без повторов и с нейтральным родом.** Тест только для пар: везде «партнёр», «друг» — только третье лицо (друг партнёра, общий друг), чтобы было ясно, о ком речь; над вопросом метка «Партнёр как друг» / «О вас как паре» / «О вас и ваших чувствах»; «мужчина/женщина» — только в вопросах о ролях.
