# Сравнение вариантов подсчёта на свежих парах — зафиксировано ДО данных (2026-10-16)

Данные: 20 новых пар p47–p66 (другой автор, без меток A/B/C, ~половина «средних»), 60 комбинаций (20 задуманных + 40 перекрёстных).
Ответы — 8 агентов (sonnet), по одной биографии. Плюс явная важность 17 сфер (imp:<сфера>, 0–10).

Критерии (независимые, по биографиям, ответов не видят):
- E — среднее двух экспертов (opus + sonnet), поле couple;
- T — семейный терапевт (динамика ссор, привязанность + планы), couple;
- S — симулятор трёх лет: together/100 · (satM+satW)/20;
- ALL — средний ранг E, T, S (главный критерий).

Варианты (формулы не меняются после просмотра):
- V0 текущий: важность 1/10/50 из крайности, смягчение по одну сторону, веса сфер RELATIONSHIP_WEIGHTS, √(S_A·S_B).
- V1 плоская важность: как V0, но вес ответа 1 у всех.
- V2 явная важность: как V1, но вес вопроса для человека = его imp:<сфера>/10 (вместо весов сфер).
- V3 пять ключевых вопросов: −среднее |a−b| по kids-02, kids-08, living-01, living-03, values-04.
- V4 стоп-факторы: V1 · (1 − 0,15 · число ключевых вопросов из V3 с |a−b| ≥ 6).
- V5 V0 + риск динамики (предрегистрация maturity, p = 0,08): V0 · (1 − 0,08 · риск).
- V6 комбинированный: V1 · стоп-факторы V4 · (1 − 0,08 · риск).
- V7 корреляция профилей (Пирсон по всем вопросам в проценте).
- V8 отличительное сходство: корреляция отклонений от среднего профиля (средний — по 92 старым персонажам).

Метрики: C-index с 95% ДИ (бутстрэп по людям, 2000), Kendall τ-b, C-index внутри 20 задуманных пар,
AUC «крепкие против проблемных» (5 vs 5), C внутри 10 «средних» пар — по критерию ALL.
Главная гипотеза: V6 > V0 по ALL на 60 комбинациях. Вторичные: V1 ≥ V0 (важность из крайности не нужна); V2 > V1; V0 − V3 (выигрыш над пятью вопросами).
