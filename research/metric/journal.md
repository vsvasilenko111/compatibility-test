**Поправки к записи 2026-10-27 (запись выше не правится):**
1. *Метка банка.* Измерялся банк **v15** (153 вопроса, коммит d262016), а не «v14». Выпущенная v14 — 156 вопросов (1a11b71).

   src/questions и HEAD; в профиле `bankVersion` берётся из `BANK_VERSION`.
2. *Проверочная часть не чистая для v13 → v15.* Все 20 проверочных пар участвовали в настройке v15: ×3 важности выбран
   лучшим из 7 вариантов по всем 60 свежим парам (priorities-eval-v14.txt), 8 переписанных вопросов и «шутка при друзьях»
   проверялись по всем 60 (eb4bd12, 1f9d6c0). 79,5 [62,8; 91,7] — не независимая оценка v15. Проверочная часть чистая

   прогон критика) — решений по ней не принималось.
3. *Вклад важности завышен.* +2,3 [0,4; 4,7] (все 60) — лучший из 7 вариантов на тех же парах, без поправки на
   множественность; кроме того, важность выводится отвечающим из той же биографии, что читают оценщики (утечка, см. ниже).
4. *Разница v13 → v15 — суммарная* за все правки разом (вопросы, шкала 5 вариантов, MATCH, важность ×3, заново

6. *Формулировка.* «Вероятно настоящий по направлению» — снимается. Правильно: **направление не установлено**

- без `split.json` скрипт падает; разбиение создаётся только `--create-split` и только если файла нет; содержимое

- согласие оценщиков сравнивается одинаковое с одинаковым: «X vs ранг(двух других)» рядом с «тест vs ранг(двух других)»
