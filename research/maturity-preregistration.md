# Проверка градуированного риска на свежих парах — зафиксировано ДО получения данных (2026-10-16)

Формула (research/scripts/maturity-graded.py, функции feats/tot), без изменений:
- ex(x) = max(0, (x − 5) / 5), пропуск → 0.
- pw = max по направлениям min(ex(regul-03 одного), ex(regul-04 другого)) — «догоняю ↔ ухожу».
- aa = max по направлениям min(ex(attach-01 одного), ex(среднее attach-02, attach-03 другого)) — «тревога ↔ пространство».
- sl = max по направлениям min(ex(trauma-06 одного), max(ex(regul-04), ex(attach-02) другого)) — «внезапная тишина».
- es = max по направлениям min(ex(trauma-05 одного), ex(regul-01 другого)) — «задели больное ↔ отвечает сразу».
- bx = min(ex(regul-01 A), ex(regul-01 B)) — оба вспыльчивые; bw = min(ex(regul-04 A), ex(regul-04 B)) — оба уходят.
- риск = pw + aa + sl + es + bx + bw; балл = процент отношений · (1 − p · риск).

Основная гипотеза: p = 0.08. Внутри новых задуманных пар (12 пар, 66 сравнений) согласие со средним двух экспертов
выше, чем у процента без штрафа (p = 0). Дополнительно смотрим p = 0.15 и сам риск отдельно.
