# 06-metric

Главная метрика теста на **рабочей части** слепой выборки (ред. 5.1, банк v16, ответы D всех 100 человек — `99faff3`,
решение по `trauma-06` — design.md 17.16, `da23017`). Считал владелец метрики по плану design.md (7, 13.3, 15.3, 16.10,
17.5, 17.7, 17.14 п. 5, 17.16). Проверочная часть (`sealed/`) не открывалась, `seal.py --open` / `--register` не
запускались: запусков проверочной части по-прежнему 0 из 3. Вызовов модели не было.

В этом файле нет коэффициентов формулы исхода, весов факторов и исходов или риска отдельных пар — только агрегаты.
**Напоминание:** люди, их тексты и ответы созданы моделью, исход — формулой автора синтетики; это проверка теста на
синтетике, а не на живых парах.

## Как считалось

- `research/blind/score_pairs.ts` — балл теста **кодом приложения**: `compare()` из `src/scoring/compare.ts`, веса сфер
  `relationshipWeight`, текущий банк v16 (128 вопросов в проценте, 18 сфер). Профиль — ответы D (вариант → `OPTION_VALUES`,
  отметка «не обсуждается» у вопросов с firm, 5 важных сфер ×3). Балл — процент «совместимости в отношениях» до
  `calibrate()` (калибровка монотонна; на рабочей части нет обрезки краёв — ранги те же, проверяется кодом). Выход —
  `metric/scores.json` (все 50 × 50 пар; частей и исходов скрипт не знает).
- `research/blind/metric_eval.py` — только пары `part == "work"` (107 пар: 29 настоящих + 78 дополнительных, 58 человек).
  ρ = Spearman(балл, −риск распада по скелету): 0 — угадывание, 1 — полное согласие. Главная строка — все пары с весами,
  при которых доли несовпадений по детям, пьянству и религиозности у дополнительных пар равны долям у настоящих (raking);
  рядом — без весов, только настоящие, только дополнительные (раздел 7). Бутстрэп по людям, 4 000 повторов, вес пары —
  произведение кратностей двоих, веса пересчитываются в каждом повторе. Выход — `metric/metric-06.json` (агрегаты);
  вклад сфер и согласие вариантов ансамбля с центральной формулой — `private/metric-06-private.json` (критик, п. 1).
- Запуск: `npx vite-node research/blind/score_pairs.ts && python3 research/blind/metric_eval.py`.

## Главная метрика (печатается дважды, 16.10)

| Строка | без важных сфер (все ×1) | с 5 важными сферами (×3) |
|---|---|---|
| **все пары, с весами (главная)** | **0,26 [−0,17; 0,60]** | **0,25 [−0,17; 0,59]** |
| все пары, без весов | 0,28 [−0,10; 0,58] | 0,25 [−0,12; 0,56] |
| только настоящие (29) | 0,31 [−0,38; 0,80] | 0,26 [−0,40; 0,76] |
| только дополнительные (78) | 0,28 [−0,16; 0,63] | 0,26 [−0,19; 0,63] |

Разница «с важными сферами − без» (парный бутстрэп): −0,01 [−0,19; 0,15] — не отличить от шума. Выводы двух вариантов
совпадают; по 16.10 при расхождении верили бы варианту без важных сфер.

**Вывод:** балл теста согласован с риском распада слабо-умеренно (≈ 0,25), но на 58 людях рабочей части **от нуля не
отличается**: 95% интервал бутстрэпа по людям включает 0.

## Ориентиры

| Ориентир | ρ (главная строка, те же веса) |
|---|---|
| оракул по скелету | 1 по построению |
| потолок самоотчёта (та же формула исхода по самоотчёту) | 0,79 [0,51; 0,92] |
| порог утечки (записан до текстов, `leak-threshold.json`, без весов) | 0,90 (потолок самоотчёта без весов 0,785) |
| **тест** | **0,26** |
| случайный балл (те же ответы, перемешанные между людьми внутри пола; справка, в плане не записано) | 95% от −0,26 до 0,25, среднее 0,00 |

- Тест далеко ниже потолка самоотчёта и порога утечки — признаков утечки нет.
- Против перемешанных ответов балл теста выше 98% перестановок (p ≈ 0,02). Это **справка**, не вывод: плановая мера —
  бутстрэп по людям, и он нуля не исключает (критик, п. 4). Два теста меряют разное: перестановка держит людей
  фиксированными, бутстрэп учитывает, что на другой выборке людей число было бы иным.
- **Тест по «правде»** (D отвечает по досье, а не по самоописанию) в плане не записан, ответов D по «правде» нет —
  не считался. Разрыв «самоотчёт → правда» по самой формуле исхода: 0,79 против 1.

## Ансамбли

| | без важных сфер | с важными сферами |
|---|---|---|
| основной, 30 формул (мин. / медиана / макс.) | 0,19 / 0,25 / 0,34 | 0,19 / 0,25 / 0,33 |
| другого устройства, 24 варианта | 0,04 / 0,25 / 0,30 | 0,04 / 0,25 / 0,29 |

По основному ансамблю число устойчиво. В ансамбле другого устройства 20 из 24 вариантов дают 0,16–0,30; ниже других —
варианты, где сильнее вес несовпадений и слабее индивидуальные риски (до 0,15), и без индивидуальных рисков (0,15);
почти ноль (0,04) — два варианта с непрерывным «требование — уход» (15.3). То есть то, что тест вообще что-то угадывает,
держится на допущении, что индивидуальные черты важнее пары; если распад сильно определяется взаимодействием
«тревожный требует — избегающий уходит», тест его не видит.

## Сферы (вклад в метрику, без весов исхода)

Вклад сферы — насколько падает ρ, если сферу убрать из процента (парный бутстрэп). Числа закрыты
(`private/metric-06-private.json`, критик, п. 1); словами:

- **тянут вверх** (больше всех): «Верность и личное пространство», «Деньги», «Конфликты»; слабее — «Юмор», «Честность»,
  «Дети» (у детей вклад заметнее с важными сферами);
- **около нуля**: общение, проявления любви, карьера, досуг, быт, ценности, родственники;
- **тянут вниз**: «Роли мужчины и женщины» (сильнее всех, особенно с важными сферами), слабее — «Привычки и здоровье»,
  «Надёжность и поддержка», «Где и как жить».
- **Ни у одной сферы** интервал вклада не исключает 0 — это направления, а не доказанные эффекты; 18 сравнений без
  поправки на множественность.
- По 17.14 п. 5 вклад **юмора, близости и родни не интерпретируется** — ни как польза, ни как вред. По 16.10 п. 1
  синтетика **не судит** о сферах вне записи человека (досуг, общение и внимание, проявления любви, питание, спорт).
- `trauma-06` не прошёл проверку вопроса 3.3: сжатие ответа, края не используются (17.16). На процент он не влияет —
  блок «зрелость» в балл не входит.

## Что не сделано или ограничено

- **Шум генерации ответов** (раздел 7: ретест 10% людей) не посчитан: ретест-ответов нет, а новые вызовы D — решение
  владельца проекта. Неизвестно, какую часть разрыва до потолка съедает сам D.
- Контроль отбраковки (раздел 6): «текст неверен» после переписываний — 0 из 200 текстов.
- Веса главной строки в 11% повторов бутстрэпа подогнать нельзя (в повтор не попала ни одна дополнительная пара с
  каким-то несовпадением); там веса остаются ближайшими достижимыми. Записывать заранее правило для таких повторов план
  не требовал; на интервал это почти не влияет (критик, п. 2).
- Мощность (2.1): на этой партии различимы только изменения ≈ 0,2 по ρ, поэтому и нижняя граница главной метрики ниже нуля.

## Итог

Тест кодом приложения на этой синтетике упорядочивает пары по риску распада со слабо-умеренным согласием, ρ ≈ 0,25
(с важными сферами и без — одинаково), но на 58 людях рабочей части **это не отличается от нуля**, и до потолка
самоотчёта (0,79) далеко. Важные сферы ничего не добавляют. Число устойчиво к разбросу коэффициентов формулы (0,19–0,34),
но почти исчезает, если распад определяется взаимодействием «требование — уход», а не индивидуальными чертами.
Как основа для решений о правках теста эта партия годится только для крупных изменений (≈ 0,2); проверочная часть не
тратилась.
