# Тест совместимости «Отношения и дружба»

Каждый проходит тест сам, отправляет ссылку — второй проходит тот же тест и видит совместимость
в отношениях и в дружбе. Сервера нет: ответы зашиты в ссылку.

## Команды

```bash
npm install
npm run dev     # локальный сервер
npm test        # тесты
npm run build   # сборка в dist/
```

## Вопросы

- Банк: `src/questions/bank.json` (порядок в файле = порядок показа).
- Манифест: `src/questions/manifest.json` — для каждой версии банка упорядоченный список `id`.
- `id` опубликованного вопроса менять нельзя: по нему связываются ответы в ссылках.
- Изменили состав или порядок вопросов → увеличьте `version` в `bank.json` и добавьте в манифест
  новую запись, **не удаляя старые** (иначе старые ссылки перестанут открываться).
- `npm test` проверяет банк: уникальность `id`, поля, сферы, нет двух вопросов одной сферы подряд.

Дизайн: `docs/superpowers/specs/2026-10-15-compatibility-test-design.md`.

## Публикация как claude.ai Artifact

```bash
VITE_PUBLIC_URL=<адрес артефакта> npm run build:artifact
```

Собирает `dist-artifact/compatibility-test.html` — один файл со встроенными стилями и скриптом.
`VITE_PUBLIC_URL` нужен, потому что внутри Artifact страница не знает свой публичный адрес, а ссылки-приглашения строятся из него.
Ссылки имеют вид `#i.<код>` (приглашение), `#r.<код>.<код>` (результат), `#q` — быстрый режим на 5 вопросов.

## Как менять вопросы

Ссылка хранит ответы по порядку вопросов своей версии банка, поэтому выпущенную версию менять нельзя — ответы молча
переставятся. Любая правка `src/questions/bank.json` (состав, порядок, текст, варианты, сферы, отметки):

1. поднять `version` в `bank.json` и добавить манифест и отметки новой версии в `manifest.json` и `firm.json`;
2. если при прежних id изменился смысл вопросов — поднять `COMPATIBLE_SINCE` в `src/questions/index.ts`
   (тогда люди с прежней версией проходят тест заново);
3. записать отпечатки: `npx vite-node scripts/release-bank.ts`; пересобрать `docs/questions.md`: `python3 scripts/questions-doc.py`.

Тест `tests/released.test.ts` не даст выложить правку без новой версии.
